# Portfolio · Karyna Tkachuk

Minimal static portfolio site: brand identity & packaging.

- `index.html`: home (work grid, about, contact)
- `ouro.html`, `velour.html`, `aoi.html`: project pages
- `cv.html`: CV (German), PDF in `files/`
- `style.css`, `script.js`: shared styles and small scripts
- `images/`: web-optimised images per project

No build step. To publish: push to GitHub and enable **Settings → Pages → Deploy from branch (main, / root)**.
